# termux-workspace-up

A simple way for me to bootstrap my workspace in Android's Termux.

I tried not to rely on Termux `proot-distro` even though it is a better way in terms of interoperability with Linux tools. For example, running `asdf` with Java SE is not possible with normal Termux. Usint proot to install Debian does.

I made this for me only, so adapt to what you need.
